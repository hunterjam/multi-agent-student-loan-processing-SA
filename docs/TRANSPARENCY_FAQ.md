## Multi-Agent Student Loan Processing Solution Accelerator: Responsible AI FAQ

### What is the Multi-Agent Student Loan Processing Solution Accelerator?

This solution accelerator is an open-source GitHub Repository that helps build a conversational AI assistant for student loan processing using a multi-agent architecture. It can be used by anyone looking for reusable architecture and code snippets to build a ready-to-use, extensible, multi-agent system that automates loan document processing and decision-making. The repository showcases a scenario of a user who wants to apply for a student loan by uploading documents and receiving automated decisions through natural conversation.

### What can the Multi-Agent Student Loan Processing Solution Accelerator do?

This is a multi-agent conversational AI solution for student loan processing. It uses the Microsoft Agent Framework to coordinate specialized agents for document extraction, validation, and loan approval decisions.

**Key Capabilities:**
- Answer general questions about student loans
- Extract structured data from uploaded PDF documents (loan applications and bank statements) using GPT-4o
- Validate extracted data across documents for consistency and completeness
- Calculate Debt-to-Income (DTI) ratios and make automated loan approval decisions
- Provide real-time streaming responses with workflow status tracking

### What is/are the Multi-Agent Student Loan Processing Solution Accelerator's intended use(s)?

This repository is to be used only as a solution accelerator following the open-source license terms listed in the GitHub repository. The example scenario's intended purpose is to help users understand how to build multi-agent systems for document processing and decision automation, and to help them perform their work more efficiently.

### How was the Multi-Agent Student Loan Processing Solution Accelerator evaluated? What metrics are used to measure performance?

The solution has been evaluated through unit tests for loan approval logic, document extraction accuracy validation, and cross-document validation checks. Users should run their own evaluation flow using their choice of evaluation methods appropriate for their use case.

### What are the limitations of the Multi-Agent Student Loan Processing Solution Accelerator? How can users minimize the impact of these limitations when using the system?

This solution accelerator can only be used as a sample to accelerate the creation of an AI assistant. The repository showcases a sample scenario of student loan processing. Users should review the system prompts provided and update them as per their organizational guidance. Users should run their own evaluation flow using the guidance provided in the GitHub repository or their choice of evaluation methods. AI-generated content may be inaccurate and should be manually reviewed. Currently, the sample repo is available in English only.

### What operational factors and settings allow for effective and responsible use of the Multi-Agent Student Loan Processing Solution Accelerator?

Users can try different values for some parameters like system prompts, AI models, and DTI thresholds shared as configurable environment variables while running evaluations for AI assistants. Please note that these parameters are only provided as guidance to start the configuration but not as a complete available list to adjust the system behavior. Please always refer to the latest product documentation for these details or reach out to your Microsoft account team if you need assistance.
